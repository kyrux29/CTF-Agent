## Mục tiêu và non-goals

M3 cho worker quan sát source và HTTP local đã khai báo thông qua typed runtime,
không cấp shell, arbitrary code, host path, Docker socket, public target hoặc
provider key cho slot/gateway. Tool output là evidence được chuẩn hóa/artifact
hóa; không phải bằng chứng solve và không thể cập nhật trạng thái `solved`.

## Thay đổi đã thực hiện

- Thêm contracts/RPC cho `source.*`, `artifacts.inspect`, `transform.apply` và
  `http.request`; input là discriminated/versioned, unknown fields bị từ chối.
- Thêm `source.list/read/search/manifest` read-only, transform allowlist nhỏ
  (base64, hex, URL, ROT13), byte quotas và source read ceiling 32 KiB.
- Thêm `TargetSpec.target_aliases`; alias bắt buộc là HTTP(S) origin trong
  `allowed_endpoints`. `FixedHttpRequestTool` tự materialize alias + path
  relative, chặn host/cookie/auth/proxy header, redirect/scope escape và JSON
  quá sâu; result không tiết lộ origin/final URL/cookie.
- Thêm tool gateway durable: lease/session/role/manifest policy, Postgres
  reserve idempotency/budget/event, immutable CAS artifact, normalizer/redactor
  cho source/transform/HTTP output. Chỉ `Decision.ALLOW` được dispatch; một
  `REQUIRE_APPROVAL` chưa có protocol M3 bị fail-closed thành deny.
- Thêm hai source-slot Compose services với mount read-only, `tmpfs`, non-root,
  `cap_drop: ALL`, `no-new-privileges`, pids/memory/CPU bounds và networks slot
  tách biệt. Không service nào mount Docker socket.
- Thêm profile Compose tổng hợp `m3`: một lệnh khởi động default stack cùng
  preflight/session initializer, live Pi, tool gateway và hai source slot. M2
  `pi-smoke` runner bị loại có chủ ý để không tranh durable job queue với live
  Pi; các profile hẹp vẫn giữ cho diagnostic.
- Thêm `provider-proxy`, một standard-library CONNECT proxy exact-host/443,
  allowlist bounded, no request/tunnel logging. Chỉ proxy join network
  `provider-public`; `pi-runner-live` nhận optional provider-key environment,
  còn API chỉ dùng key request-local của browser qua proxy internal.
- Thêm test source/transform/HTTP slot, remote RPC, database idempotency/budget,
  provider proxy, Node environment-proxy behavior và static Compose topology.
- Bổ sung `extraPaths` pyright cho workspace source roots và helper settings
  `from_environment()` có typed Pydantic-constructor seam; không dùng type-ignore
  hay nới validation.

## Quyết định chính

1. Worker gửi alias thay vì URL. Gateway/slot giữ manifest đã ký và chỉ slot có
   thể ghép destination, nên prompt injection không thể đổi host qua tool input.
2. Source input không được biến thành runtime capability. Upload archive chỉ là
   receipt/triage; source mount là deployment-time bind của operator.
3. Provider key không đi qua tool gateway/source slot/proxy hoặc API
   environment. Browser key chỉ đi trong một request Control API qua proxy;
   proxy chỉ relay bytes TLS sau CONNECT hợp lệ và không hiểu provider protocol.
4. Không tạo challenge demo để "pass" E2E. Lab và flag phải do operator cấp,
   verifier độc lập vẫn là authority duy nhất ở M5.
5. Docker Compose là entry point deploy duy nhất. Package manager/runtime host
   không phải dependency triển khai; source đã review và secret vẫn là input
   operator, không bake vào image hoặc Compose file.

tạm thời và explicit provider acknowledgement như endpoint JSON trước đây;
response là NDJSON gồm đúng các checkpoint tuần tự sau và một terminal event:

1. `request_accepted`;
2. `receipt_loaded`;
3. `evidence_prepared`;
4. `provider_request_started`;
5. `provider_response_received`;
6. `result_validated`;
7. `result_saved`;
8. terminal `result` hoặc `error`.

Các summary là chuỗi code-owned cố định, không phải token stream hay
chain-of-thought. Progress không chứa prompt, provider response body, diagnostic
thô, archive path/excerpt, API key hoặc flag. Provider failure chỉ cho phép mã
public đã review; browser còn mirror exact stage/summary allowlist, fail-closed
khi schema/sequence/kind/text lạ, giới hạn 16 event và buffer 4 MiB. API key bị
xóa khỏi request model trước frame đầu tiên,
chỉ còn trong coroutine đang chạy, rồi được clear khi complete, error hoặc client
disconnect; provider session được đóng có timeout. Endpoint JSON `/triage` được
giữ để không phá client hiện có.

Web thêm evidence rail nhỏ ở panel AI: đang chạy hiển thị **AI is working** và
`n/7`, metric receipt đổi thành **Working**; hoàn tất chuyển sang **Processing
summary** và `7/7`; lỗi giữ checkpoint cuối ở trạng thái stopped. Dòng chú
thích nói rõ đây là runtime stage đã xác
thực, không phải private model reasoning. Nginx đặt `proxy_buffering off` bên
cạnh request streaming để checkpoint tới browser ngay thay vì chờ terminal
receipt. Hướng dẫn sử dụng đã được đồng bộ tên nút hiện tại và endpoint stream.
