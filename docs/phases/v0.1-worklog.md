## Scope decision

The source blueprint describes a multi-release roadmap, not one safe atomic
implementation. This delivery targets a narrow public `v0.1` acceptance path:
import an authorized Web-lab manifest, create evidence-backed state, execute
exact-scope typed tools, record a proof-of-concept artifact, and replay the
restricted declarative HTTP-plan literal parsed from that sealed artifact after
two logical fixture resets. The exported `solve.py` is not executed by this
profile. A small evidence console is included for the requested demo, but
multi-provider routing, portfolio search, long-term memory, Temporal,
Kubernetes, and third-party plugins remain explicitly out of scope.

The deterministic demo backend is the required CI path. A real Codex adapter is
an optional smoke path and must never make tests depend on credentials.

## Assumptions

- Linux, Python 3.12+, Node 22.12+, and pnpm 10.18.3 are available.
- Docker is optional for the deterministic CLI demo and required only for the
  Compose integration profile.
- PostgreSQL is the production-shaped store; SQLite is the default for the CLI
  demo, host-local API, and fast single-process tests.
- The bundled demo lab is intentionally vulnerable and may only run locally.
- Production execution of untrusted code requires a rootless OCI runtime or
  gVisor. No insecure fallback is presented as a production boundary.

## Current implementation tree

```text
apps/api             FastAPI composition root and live stream
apps/cli             Typer workflow and artifact export
apps/web             evidence-centric React console
packages/domain      strict manifests and domain contracts
packages/events      immutable event envelope and replay
packages/db          SQLAlchemy store and migrations
packages/policy      scope/budget/approval decisions
packages/providers   provider-neutral worker contract and fake/Codex adapters
packages/tools        typed file/source/HTTP tools and artifact storage
packages/sandbox     sandbox contracts and fail-closed capability checks
services/orchestrator deterministic single-branch run loop
services/verifier    declarative reset/replay and provenance validation
support/examples/labs        deterministic JWT, SSTI, and IDOR lab fixtures
tests                unit, integration, and E2E suites with security regressions
```

## Dependencies and rationale

- FastAPI/Uvicorn/Pydantic: typed ASGI control API and OpenAPI contracts.
- SQLAlchemy/Alembic: portable persistence with a PostgreSQL migration path.
- httpx: bounded async target interaction and deterministic ASGI tests.
- Typer/Rich: one-command local demo and inspect/export workflows.
- React/Vite/TypeScript: compact live evidence console.
- pytest/Ruff/Pyright: behavioral, static, and security-focused regression gates.

## Reproducible commands

```text
uv sync --frozen --all-packages --all-groups
pnpm install --frozen-lockfile
just check
just demo
just demo-verify
```

## Acceptance gates

- exact-scope policy deny paths pass;
- confirmed facts always cite evidence or a human assertion;
- event stream is append-only and deterministically replayable;
- exploit cannot set `solved` directly;
- verifier resets logical fixture state and succeeds exactly 2/2 with the
  declarative HTTP plan;
- masked flag, `solve.py`, `trace.jsonl`, `writeup.md`, and
  `verification.json` are exported;
- backend and frontend lint/type/test/build checks pass;
- residual sandbox limitations are visible in CLI output and release docs.
