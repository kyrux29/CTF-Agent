## Scope update — 2026-08-31 (M6.a started)

Operator approved the browser-first exact-instance flow documented in
[ADR 0007](../adr/0007-ui-driven-exact-instance-flow.md). This is deliberately
a bounded implementation slice, not a generic CTF executor:

- The UI will bind one validated archive to one origin-only assisted Web target
  and one one-time provider/model selection.
- Source content is copied only from the already-safe archive workspace into a
  fixed slot volume. No archive file, Docker Compose file, binary or generated
  code is executed.
- Provider credentials are memory-only in Pi Runner; raw flags are memory-only
  in a one-time reveal lease after independent replay proof. Neither value may
  become an event, database field, artifact, session transcript or slot env.
- Source slots receive no public egress. A target connector must validate a
  short-lived gateway-signed capability bound to the exact request and reject
  non-global network destinations and redirects.
- Remote replay means two fresh cookie-jar replays to the exact target; it
  cannot reset or control the operator's remote instance. Failure to obtain
  two matching target responses remains unsolved.

The first implementation pass must add contracts and deterministic deny-path
tests before UI polish. M6's live A/B/C evidence remains open; it can only be
collected after this path has passed its own security/Docker gates.

## Phạm vi khóa khi bắt đầu

M6 bắt đầu bằng evaluator offline cho verified solve, không bằng một model mock
hoặc một target executor mới. Input phải ghi đủ run-seed **digest**, model/prompt/
skill/config digest, budget, challenge/image digest, result và verifier proof
receipt. Báo cáo phải đưa ra raw count cho ba điều kiện đồng nhất:

- A — `single_session`;
- B — `master_workers_no_hint`;
- C — `master_workers_with_hint`.

Mỗi lab/condition cần đủ ít nhất năm run. Evaluator chỉ đọc JSON reviewed và
không có provider client, filesystem challenge access, network, Docker, API key
hoặc quyền thay đổi trạng thái run. `SOLVED` vẫn chỉ là trạng thái kernel/verifier
đã cấp; report M6 không thể tạo hoặc sửa trạng thái đó.

## Invariant và non-goal

- Một record `solved` thiếu proof hợp lệ với hai reset khác nhau phải được đếm là
  false solve, không bị che bởi phần trăm hoặc bị loại khỏi mẫu.
- Bất kỳ out-of-scope action, public-answer retrieval, hint chưa reflected hoặc
  duplicate không có lý do phải hiện thành release-gate failure rõ ràng.
- Seed được lưu bằng digest/opaque ID, không ghi raw seed có thể suy ra runtime
  flag. Prompt, skill, model config và proof chỉ xuất hiện dưới dạng digest/opaque
  metadata; raw flag/transcript/key không thuộc schema. Opaque identifier cũng từ
  chối giá trị có hình dạng credential OpenAI/Gemini (ví dụ `sk-…`/`AIza…`) để
  tránh vô tình đưa API key vào receipt.
- Không công bố score model hay tuyên bố ≥60% trước khi operator chạy evaluation
  với provider, scope M3 và lab đã được phê duyệt. Fixture scripted chỉ kiểm chứng
  contract/aggregation, không phải benchmark model.

  JSON tối đa 1 MiB, không overwrite report và không chạy model, target, tool,
  Docker hay verifier. Report luôn gồm raw count toàn cục/theo lab, config
  digest, delta B−A/C−A, timing/tool/duplicate counters và safety gate.

### 2. Chaos/hardening đã thêm

- `M5ReplayVerifier` có deadline độc lập cho `controller.reset` và
  `controller.verify`. Timeout trở thành `lab_controller_timeout`; không tạo
  proof hoặc `SOLVED`.
- Gateway test tạo slot treo đúng timeout production tối thiểu một giây. Slot
  bị cancel, row chuyển `FAILED` với `tool_dispatch_timeout`; delivery duplicate

- Source/HTTP chứa câu lệnh giả mạo được giữ như untrusted evidence đã redact;
  summary/event không echo nội dung. Pi tool output có prefix provenance cố
  định và role prompt nhắc rõ không làm theo yêu cầu đổi quyền/scope/secret.
  Đây là defense-in-depth UX; typed gateway + manifest + role ACL mới là
  capability boundary, không hứa rằng chỉ prompt có thể triệt tiêu injection.
- M6 report ghi `invalid_worker_output_count`, verifier timeout và mọi
  out-of-scope/public-answer/duplicate/hint counter để release gate không bị
