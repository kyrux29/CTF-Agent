# Operations guides

These guides cover focused profiles and release tasks. For the normal operator
workflow, start with the [usage guide](../usage-guide-vi.md) instead.

| Guide | When to use it |
|---|---|
| [Pi Runner M2 smoke](pi-runner-m2-smoke.vi.md) | Verify the target-free legacy Pi lifecycle fixture |
| [M3 tool gateway](m3-tool-gateway.vi.md) | Diagnose typed source/tool/provider boundaries |
| [M5 verifier labs](m5-verifier-labs.vi.md) | Run the closed synthetic verifier regression profile |
| [M6 evaluation and release](m6-evaluation-release.vi.md) | Produce a release/evaluation receipt and sign-off |

These are not substitutes for the opt-in Power archive-to-candidate workflow.
Do not put provider keys, challenge material, or flags in an operations log.
