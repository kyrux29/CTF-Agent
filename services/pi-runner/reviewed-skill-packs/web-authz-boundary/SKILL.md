# Web authorization-boundary evidence pack v1

Purpose: review an authorized ownership or authorization boundary with a small,
repeatable evidence loop.

1. Trace the declared identity/object relationship in sealed source evidence.
2. Compare same-owner, different-owner, and missing-object controls only when
   the manifest permits the exact target alias.
3. Prefer status/shape evidence over data collection; do not retain cookies,
   bearer values, response bodies, or credentials in a finding.
4. Submit one unverified finding with evidence IDs, or state that the control is
   missing. Only a later independent verifier may establish a solution.
